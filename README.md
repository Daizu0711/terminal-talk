# 📡 Terminal Talk

**Terminal Talk** は、ターミナル上でBluetooth（BLE: Bluetooth Low Energy）を使用して、近隣の端末同士で直接チャットができるP2Pターミナルチャットアプリケーションです。

---

## ✨ 主な特長

1. **Bluetooth メッシュ中継（マルチホップリレー）**:
   - 自分の電波（約10〜20m）が直接届かない遠くの相手でも、中間にいる他のTerminal Talkユーザーが自動的にパケットをバケツリレー中継（Hop）してメッセージを届けます。
2. **DM（1対1個別チャット） ＆ グループチャット**:
   - 全員に聞こえる全体グループチャットと、特定の相手を指定して送信する個別DMモードを自由に切り替え可能。
3. **連絡先履歴の自動保存 (`contacts.json`)**:
   - 過去にすれ違った・チャットしたユーザーの情報をローカルに保存。電波圏外でも後からDMを送信（メッシュ中継）できます。
4. **コマンド1行で即時ダウンロード＆起動**:
   - Pythonがまだインストールされていない相手の端末でも、インストーラーが自動的にOS環境を判定し、Python 3や依存ライブラリを全自動セットアップ。

---

## 🚀 インストール & 起動

### 1行コマンドでダウンロード & インストール

```bash
# GitHub経由でワンライナーインストール
curl -fsSL https://raw.githubusercontent.com/YOUR_USERNAME/terminal-talk/main/install.sh | bash
```

またはローカルで実行：
```bash
bash install.sh
```

---

## 💬 使い方

起動後は、文字を入力して Enter を押すと現在のチャンネル（グループチャットまたは指定した相手へのDM）にメッセージが送信されます。

### コマンド一覧

| コマンド | 説明 |
| :--- | :--- |
| `メッセージ` | アクティブなチャンネル（全体またはDM相手）へメッセージ送信 |
| `/group` または `/all` | 全体グループチャットモードに切り替え |
| `/chat <名前>` | 特定の相手との個別の1対1 DMモードに切り替え |
| `/msg <名前> <本文>` | チャンネルを切り替えずに特定の相手へ直接DMを送信 |
| `/contacts` | 過去に出会った保存済み連絡先一覧を表示 |
| `/peers` | 現在自分の電波圏内にいる直接接続中の端末一覧を表示 |
| `/nick <名前>` | 自分のニックネームを変更 |
| `/share` | 友達に共有するための1行ダウンロードコマンドを表示 |
| `/clear` | チャット画面をクリア |
| `/help` | ヘルプを表示 |
| `/quit` | アプリを終了 |

## 🔗 Bluetooth メッシュリレーの仕組み

```
[あなた (Sota)] ------(BLE)------> [端末B (中継)] ------(BLE)------> [相手 (Target)]
  (圏外の相手へ送信)               (自動バケツリレー)                (メッセージ受信!)
```

- パケットにはTTL（生存時間: 初期値5ホップ）と重複防止機能（UUID判定）が組み込まれており、ネットワーク内での無限ループを防ぎながら効率的にメッシュ中継を行います。
